iPadで牌譜をNAGA用に変換する

Safariにログインして取得する試作品です。 ログインできることは利用者が確認済みですが、iPad実機での取得と変換画面への受け渡しは利用者が確認済みです。NAGAサーバーでの受理は未確認です。 補助ツールの「準備OK」は導入完了を表すだけで、牌譜取得の成功ではありません。 URLだけの匿名取得には対応していません。NAGAの注文は行いません。

取得方法の選び方

方法できること・制約
ブックマークレット追加アプリ不要。雀魂ページで実行した後の牌譜通信を取得します。ページ移動・再読み込みのたびに実行が必要です。
Safari拡張（Userscripts）読み込み開始時から取得ツールを有効にできます。別途導入と雀魂サイトへの権限設定が必要です。料金が表示されたら導入しないでください。
共有メニューだけURL共有だけでは牌譜本文や終了済み通信を取得できません。補助ツールで先に取得する必要があります。

初回だけ：無料のブックマーク方式

  1. Safariでアプリを開きます。「使い方」のSafari用コードをコピーをタップ。コピーできなければ「コピーできない場合」を開き、コード欄を長押し→すべてを選択→コピーします。
  2. Safariの共有ボタン（四角から上向き矢印）→ブックマークを追加を選び、名前を「牌譜を保存」にして保存します。
  3. Safariのサイドバー／ブックマーク一覧で「牌譜を保存」を長押しして編集します。URL欄を全選択し、コピーしたコード全体を貼り付けます。先頭が javascript: であることを確認し、保存します。名前の欄ではなくURL欄に貼り付けてください。
  4. Safariの雀魂Web版に自分でログインし、登録したブックマークを開きます。右下に準備OKの小さなパネルが出れば、このページで有効です。

ブックマーク方式は雀魂のページを再読み込みするたびに実行が必要です。自動実行したい場合は下のSafari拡張方式を使います。雀魂のネイティブアプリ内では動きません。

毎回：共有URLから牌譜を開いて変換

  1. 雀魂で牌譜の共有URLをコピーします。アプリの雀魂のURLタブへ貼り付け、URLを確認します。このボタンはURLの形式確認で、牌譜を取得するボタンではありません。
  2. 雀魂で牌譜を開くをタップします。必要なら自分でログインしてください。ページ移動・再読み込み後は取得ツールを再実行し、準備OKの表示後に牌譜を開きます。既に牌譜を開いた後にツールを有効にした場合、一度牌譜一覧へ戻って開き直します。
  3. 「取得できました」と表示されたら変換画面に送るをタップ。新しいSafariタブで変換画面が開き、牌譜が読み込まれます。牌譜本体はタブ間で渡し、URLやサーバーには載せません。
  4. 変換する局を30局以下に選びます。匿名化は初期値ONです。選んだ局をNAGA用に変換→コピーするをタップします。自動コピーできなければ、出力欄を長押ししてコピーします。
  5. NAGAの画面で、自分でログインしてカスタム牌譜解析を選びます。「URL解析」の1行入力欄ではありません。ログイン後にタブが戻る場合も「カスタム」を選び直してください。出力を貼り付け、東風／半荘（東南）と対象プレイヤーを確認します。解析を押すとポイントを消費するため、この確認手順では押さないでください。本アプリからは注文しません。

直接渡せないとき：ファイル方式

  1. 雀魂の補助ツールで牌譜ファイルを保存をタップします。Safariのダウンロードを許可します。
  2. 「ファイル」アプリのダウンロードで majsoul-数字.msr.json を確認します。保存先がiCloud DriveまたはこのiPad内のどちらかは、Safariのダウンロード設定に従います。
  3. 変換アプリに戻り、ファイル・データ→牌譜ファイルを選ぶ→ブラウズ→ダウンロードから保存したファイルを選びます。
  4. 局数が表示されたら、上の手順4以降と同じです。使い終わった実牌譜ファイルは必要に応じて自分で削除してください。アプリは履歴を保存しません。

任意：Safari拡張で自動実行する

無料で利用できる版のUserscriptsを利用する方法です。App Storeに料金が表示される場合はインストールせず、上のブックマーク方式を使ってください。有料の拡張は不要です。

  1. Userscriptsを開き、スクリプト保存先フォルダを確認します。
  2. iPadの設定→アプリ→Safari→機能拡張（OSによっては設定→Safari→機能拡張）でUserscriptsを有効にし、雀魂のサイトに対して許可します。すべてのサイトへの許可は必要ありません。
  3. Safariで取得用スクリプトを開くを選び、Safariの機能拡張メニューからUserscriptsを開いてインストールします。または capture.user.js を保存先フォルダに置きます。
  4. 雀魂を再読み込みし、準備OKを確認して牌譜を開きます。スクリプトは @run-at document-start・@inject-into page が必要です。変更せず使ってください。

Userscripts公式のiPad手順も確認できます。雀魂のCSPや更新によって注入できない場合は、設定を弱めずエラー内容を確認してください。

v0.3.2：実データを確認する（注文不要）

  1. アプリ最下部のv0.3.2を確認。通常どおり取得し、まず1局だけ変換します。
  2. 「復号した局情報・打牌情報を確認」で局名・本場・開始点・配牌・打牌配列を、雀魂の同じ局と見比べます。配列の説明は画面内にあります。
  3. NAGAの入力欄の全文をコピーし直し、牌譜の橋の「NAGAへ貼ったURLを端末内で検査」へ貼り付けます。「生成したデータと復号後の全項目が一致」を確認します。データは送信されません。
  4. アプリの生成エンコードは1回です。NAGA公式にはURLSearchParamsとdecodeURIComponentの2段階復号があり、ペイロードを2回エンコードしたURLでも復号できる場合があります。%25の見た目だけで異常とは判断せず、検査結果を確認してください。
  5. NAGAの表示額は「選択タイプ数別の1局単価×入力局数」です。11NPだけではタイプ数を断定できません。1行だけ貼り、選択されているNAGAタイプと表示額を確認します。「解析(1局…NP)」は空欄でも表示されるため、ボタン表示は牌譜の正当性を保証しません。解析は押さないでください。

v0.3.3：複数局の貼り付けを確認

  1. 9局選択なら、変換後にコピーした表示が「9局・9行（LF改行8個）」になっていることを確認します。
  2. NAGAのカスタム欄へ貼り、全文をコピーし直して本アプリの検査欄へ貼り戻します。「9行」「文字列も完全一致」を確認します。画面の自動折り返しは改行ではありません。
  3. 「9局分のURLが1行に結合」と出た場合は「改行を復元して検査」を押します。生成した内容と一致する場合だけ復元できます。上の「コピーする」で再コピー、または「テキスト保存」でファイルから全文コピーを試します。
  4. 内容不一致・欠落は自動補完しません。元の雀魂から読み込み直してください。NAGAで解析ボタンを押す検証は行いません。

1局のNAGA解析完了は利用者が確認済みです。複数局は2・3・5・9局の公式入力チェックをローカルで実行済みですが、iPadからの一括解析完了は未確認です。鳴き位置の警告は、ポンされた牌と鳴かれた席を照合する判定へ修正しました。警告のみで誤変換と断定しません。

v0.3.4：原因を特定するための比較診断

  1. 最下部のv0.3.4を確認します。9局選択して変換し、「コピーする」を押します。コピーAPI実行直前の全文が記録されます。
  2. NAGAへ貼り付けた全文をコピーし直し、同じ「牌譜の橋」のタブへ戻ります。比較終了までページを再読み込みせず、局選択も変更しません。
  3. 「NAGAへ貼ったURLを端末内で検査」の貼り戻し欄へ全文を入れます。以前成功した同じ半荘の1局URLが残っていれば任意欄へ入れます。比較用の新たな注文は不要です。
  4. 「コピー前後を比較診断」を押します。失敗した行と処理、コピー前後の行数・文字数、最初の相違位置、成功1局との一致を確認します。途中の行が不正でも、残りの行を含む結果が残ります。
  5. 調査用には「診断レポートだけコピー」の内容を共有できます。元URL・対局者名・打牌配列は含みません。全文を共有したい場合は本人が内容を確認してください。

今回は原因未確定のため、診断前に改行復元や手動でのエンコード修正を行わず、そのまま比較してください。解析ボタンは押しません。記録はメモリ内だけにあり、再変換・選択変更・別牌譜の読み込み・ページ再読み込みで消えます。コピー前の記録がない場合は、その旨を表示し、原因を推定しません。

困ったとき

NAGAで「urlの形式が違います」と表示される

NAGAの「URL解析」欄は通常の天鳳牌譜ID用です。本アプリの出力は「カスタム牌譜解析」用です。「カスタム」タブの大きな複数行欄へ貼り付けてください。先頭は https://tenhou.net/5/#json= です。URLをSafariのアドレス欄で開いたり、アドレス欄からコピーし直したりせず、本アプリの「コピーする」で全文をコピーします。複数局は1局1行のまま貼り付けます。再テストでは解析ボタンは押さないでください。

準備OKが出ない／取得待ちのまま

Safariの雀魂Web版か確認します。共有URLを別タブで開いた場合、そのタブでも実行します。ページ再読み込み後はブックマークを再実行。既に表示済みの牌譜は取り出せないため、一覧へ戻って再度開きます。「準備OK」のままなら対象要求を観測していません。「牌譜要求を検出」なら要求は観測しましたが応答待ちです。ゲーム内でキャッシュされた牌譜は要求が出ない場合があります。再読み込み→補助ツール有効化→牌譜を開く順で試してください。Web Worker内の通信、CSP、他の拡張、雀魂の更新でも動かない場合があります。安全設定の解除や認証情報の提供はしないでください。ログイン情報やトークンを他人に渡す必要はありません。

変換画面へ渡せない

新しいタブが開いているか確認します。ポップアップが拒否されたり、ホーム画面アプリとの別ウィンドウになったりする場合があります。無理にブラウザの安全設定を変えず、牌譜ファイルを保存して読み込む方法を使ってください。

三人麻雀・特殊ルール・大きな牌譜でエラー

通常の四人麻雀のみ対応、ファイル上限8MBです。別URLにある大きな牌譜本体の取得がCORS等で拒否された場合も、成功したようには扱いません。

ホーム画面とオフライン

Safariの共有→ホーム画面に追加。一度オンラインでアプリを開き、読み込みを終えてから使います。保存済みファイルの変換はオフラインでも可能です。雀魂からの取得とNAGAの利用には通信が必要です。Safariがキャッシュを削除した場合は再度オンラインで開いてください。
